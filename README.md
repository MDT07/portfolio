# CV Эмир Семенов [ПРОФИ.РУ]

Интерактивное RU/EN портфолио web-разработчика: full-cycle web-продукты, интерфейсы, AI-боты и автоматизация. Главная experience-сцена использует живую 2D-схему и небольшой нативный WebGL/GLSL микроакцент с CSS fallback; кейсы собираются из типизированного JSON data-layer без runtime-зависимости от Markdown/MDX.

## Локальный запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:3000`. Английская локаль доступна по `/en`.

## Проверка production-сборки

```bash
npm run validate
npm run lint
npm run typecheck
npm run build
npm run qa:premium
```

Архитектура, маршруты и правила контента описаны в [portfolio.md](./portfolio.md).
