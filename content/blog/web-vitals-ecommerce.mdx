## Почему именно магазин

Google давно связал Core Web Vitals с ранжированием, но для e-commerce это не про SEO — это про деньги. Каждые 100 мс задержки на мобильной витрине — измеримые проценты брошенных сессий. Разберу три метрики в местах, где они бьют по конверсии больше всего.

## LCP — карточка товара

Largest Contentful Paint на странице товара — почти всегда главное фото. Типовые ошибки: изображение грузится через `lazy-loading` (да, главное фото тоже ленивят), без `fetchpriority="high"`, в формате PNG вместо AVIF/WebP.

Что делаю в проектах:

- Главное фото — `priority`, `fetchpriority="high"`, никакого lazy-load
- AVIF с фолбэком WebP, `srcset` под три брейкпоинта
- Преконнект к CDN изображений: `<link rel="preconnect">` экономит 100–300 мс на handshake

Цель — LCP ≤ 2.0s на мобильном 4G. Это достижимо без единой жертвы в дизайне.

## INP — фильтры каталога

Interaction to Next Paint замеряет отклик интерфейса. Каталог с 500+ SKU и фильтрами — классическое место, где каждый клик по чекбоксу пересчитывает всё и фризит поток.

Приёмы:

- Фильтрация через `startTransition` — UI остаётся отзывчивым, пока React перерендеривает список
- Виртуализация длинных списков (или честная пагинация — она недооценена)
- Дебаунс не по времени, а по кадру: один `requestAnimationFrame` на серию кликов

Хороший ориентир — INP ≤ 200ms. Пользователь не должен видеть, что интерфейс «думает».

## CLS — чекаут

Cumulative Layout Shift в чекауте — это не эстетика, это клики не по тем кнопкам. Виновники почти всегда одни и те же: поздно подгружающиеся баннеры рассрочки, виджеты доставки, веб-шрифты без `size-adjust`.

Рецепт скучный и рабочий: резервировать место под каждый асинхронный блок, `font-display: swap` + подобранный fallback с близкими метриками, скелетоны вместо спиннеров — они держат геометрию страницы.

## Чем измерять

Лабораторные данные (Lighthouse) — для разработки. Полевые (CrUX, RUM) — для правды. Смотрю на 75-й перцентиль по мобильным, а не на среднее: среднее врёт, хвост распределения — это ваши реальные покупатели на слабых устройствах.

**Итог.** Web Vitals — это не чек-лист для галочки, а три конкретных места в воронке. Карточка, каталог, чекаут — закройте их, и метрики конверсии отреагируют раньше, чем вы успеете написать отчёт.
