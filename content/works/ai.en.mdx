## Problem

AI integrations have become a separate studio product, but the landing page has to prove we don't just plug in APIs — we design assistants for business tasks. Buyers need to see: what the chat looks like, how behavior changes across models, and how the assistant fits into web / Telegram / WhatsApp. The goal was to make the page itself a demonstration of the technology.

## Solution

A single self-contained `index.html` — a flagship landing page for the AI direction. Style: deep dark background `#08080F`, live aurora of blurred blobs, glassmorphism panels, grain. Main font Manrope (Cyrillic) + Onest + JetBrains Mono. The signature feature: selecting an AI model recolors the entire page via CSS variables `--acc`/`--acc2` to match the brand colors of that model.

## What's inside

- **Hero** — gradient headline, page "core" switcher (GPT-5 / Gemini 2.5 / Claude 4 / Llama 3.3 / GigaChat / YandexGPT), 4 count-up metrics
- **Live demo** — assistant builder: model × role (sales / support / HR) × channel (web / Telegram / WhatsApp). The chat rebuilds: custom latency, response style, channel skin; text streaming, typing indicator, hints; local intent engine
- **Cases** — 6 cards with mini-presentations: TG chat mocks, web widget, WhatsApp, call waveform with scoring, HR pipeline, voice
- **Models** — comparison table (speed / quality / price, animated bars) + priority picker with recommendation
- **Process** — animated SVG pipeline (running dot via animateMotion) + 4 steps
- **Packages** — Pilot / Business / Enterprise
- **FAQ** — security, 152-FZ, on-premise models
- **CTA** — form with email / phone / @telegram validation

## Architecture and stack

Zero dependencies: semantic markup, CSS custom properties for theme and accents. Model switching changes `--acc`/`--acc2`, response speed, and message style. The chat runs on a local knowledge base: 8 intents × flavor for the selected model, with text streaming and a typing indicator. Comparison bars, count-up counters, and the SVG pipeline are animated via requestAnimationFrame and CSS. Accordion, reveal animations, and form validation are vanilla JS. Google Fonts: Manrope, Onest, JetBrains Mono.

## Result

A landing page that doesn't describe AI but shows it in action: the interface recolors to match the model, the chat works across channels and skins, and model comparison includes a recommendation. QA run — 21 assertions: boot, model switching, chat, recommendation picker, counters, accordion, validation, overflow — green on desktop and mobile.
