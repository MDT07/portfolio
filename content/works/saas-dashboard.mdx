## Проблема

Аналитические дашборды страдают от двух крайностей: либо перегруженные «корпоративные» панели с десятком цветов и теней, либо бедные виджеты, с которых невозможно считать состояние продукта. Нужен интерфейс уровня Linear и Vercel: плотный по данным, но спокойный, где каждое число читается мгновенно.

## Решение

Полноценная app-оболочка платформы продуктовой аналитики «METRIC»: сайдбар, топбар, рабочая область. Строгая тёмная тема, один сигнальный акцент, моноширинные метрики с табулярным выравниванием цифр. Один самодостаточный HTML-файл — открывается без сборки и сервера, весь интерактив на чистом JS.

## Что внутри

- **KPI-карточки** — MAU, DAU/MAU, конверсия, churn: animated counters при загрузке, дельты в процентах, SVG-спарклайны
- **Главный график** — area/line chart на чистом SVG: сетка, оси с датами, hover-crosshair с тултипом, переключатель метрик (пользователи/сессии/события) с morph-анимацией линии
- **Переключатель периода** — 7/30/90 дней, график перестраивается под новый массив данных
- **Live-обновления** — раз в 5 секунд новая точка с плавным сдвигом окна, индикатор «обновлено N сек назад»
- **Таблица «Топ событий»** — сортировка по клику на заголовок (asc/desc со стрелкой), бары доли, цветовые дельты
- **Воронка** — 4 ступени с процентами и конверсиями между шагами, анимированные бары
- **Статусы системы** — API / CDN / Database: цветные индикаторы, uptime и latency
- **Сворачиваемый сайдбар** — состояние сохраняется в localStorage

## Архитектура и стек

Один `index.html` без зависимостей: семантическая разметка, дизайн-токены на CSS custom properties, весь рендер — vanilla JS. График строится программно из массивов данных: детерминированный ГПСЧ (mulberry32) с weekly-сезонностью даёт правдоподобные ряды, одинаковые при каждом открытии; live-тики продолжают ту же seeded-последовательность. Анимации на requestAnimationFrame с easeOutCubic, morph-переходы линии — интерполяцией точек path. Числа — `font-variant-numeric: tabular-nums`, метрики — JetBrains Mono.

## Результат

Data-dense интерфейс без визуального шума: монохромная база, один акцент, статусные цвета только там, где они несут смысл. Шаблон работает как живое демо прямо в браузере и легко переносится в любой стек — токены и компонентная структура готовы к миграции на React/Vue.
