## Problem

Analytics dashboards tend to fall into one of two traps: overloaded "enterprise" panels with a dozen colors and shadows, or sparse widgets you can't read product state from. The goal was an interface at the level of Linear and Vercel: data-dense yet calm, where every number reads instantly.

## Solution

A full app shell for the "METRIC" product analytics platform: sidebar, topbar, workspace. A strict dark theme, a single signal accent, monospaced metrics with tabular figure alignment. One self-contained HTML file — opens with no build step or server, all interactivity in pure JavaScript.

## What's inside

- **KPI cards** — MAU, DAU/MAU, conversion, churn: animated counters on load, percentage deltas, SVG sparklines
- **Main chart** — area/line chart in pure SVG: grid, date axes, hover crosshair with tooltip, metric switcher (users/sessions/events) with line morph animation
- **Period switcher** — 7/30/90 days; the chart rebuilds around the new data array
- **Live updates** — a new point every 5 seconds with a smooth window shift, plus an "updated N sec ago" indicator
- **Top events table** — click-to-sort headers (asc/desc with arrow), share bars, colored deltas
- **Conversion funnel** — 4 stages with percentages and step-to-step conversion rates, animated bars
- **System status** — API / CDN / Database: colored indicators, uptime and latency
- **Collapsible sidebar** — state persisted to localStorage

## Architecture & stack

A single `index.html` with zero dependencies: semantic markup, design tokens via CSS custom properties, all rendering in vanilla JS. The chart is built programmatically from data arrays: a deterministic PRNG (mulberry32) with weekly seasonality produces plausible series that look identical on every open; live ticks continue the same seeded sequence. Animations run on requestAnimationFrame with easeOutCubic; line morphs interpolate path points. Figures use `font-variant-numeric: tabular-nums`, metrics are set in JetBrains Mono.

## Result

A data-dense interface without visual noise: monochrome base, one accent, status colors only where they carry meaning. The template runs as a live demo right in the browser and ports easily to any stack — tokens and component structure are ready for migration to React/Vue.
