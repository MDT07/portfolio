# Шаблон «Девелопмент / Строительство»

Демонстрационный сайт строительной компании «МЕРИДИАН».

## Запуск

Открыть `index.html` в браузере. Никакой сборки не требуется.

## Секции

1. **Hero** — полноэкранный, фоновое фото объекта, CTA
2. **О компании** — ключевые цифры (лет, проектов, м², % в срок)
3. **Проекты** — 6 карточек с фильтром (жилые / коммерческие / инфраструктура)
4. **Технологии** — 6 карточек (BIM, энергоэффективность, модульность, геомониторинг, умный дом, циркулярные материалы)
5. **Контакты** — адрес, телефон, форма обратной связи

## Стиль

Строгий реализм по `DESIGN.md`: монохром (#0A0A0A, #111111, #242424), один акцент #0070F3, Inter + JetBrains Mono, модульная сетка, 8px radius на карточках.
