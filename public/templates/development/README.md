# PRIMARY TERRA — демо-шаблон девелоперской компании

Самодостаточный HTML-файл: открывается в браузере без сборки и сервера.
Awwwards-уровень подачи в рамках строгого инженерного реализма (DESIGN.md §10 — кинематографический слой).

## Запуск

Открыть `index.html` в браузере — всё.

## Что внутри

- Hero: fluid-типографика до 120px с line-mask reveal, clip-path «проявление» фото, параллакс, live-часы MSK, velocity-marquee
- 001 — глава «Цифры вместо обещаний»: редакционный stat-rail с анимированными счётчиками, hairline-сетка
- 002 — редакционный индекс проектов 01–06: фильтры-табы с подсчётом, hover-превью фото, следующее за курсором, архивная нумерация «n0.0xx», figure captions
- 003 — светлая инверсия-глава (paper #EDEDED): curtain-wipe переход, spec-sheet аккордеон технологий (single-open)
- 004 — контакты: state-machine кнопка формы (Отправить → Отправляем… → Принято ✓) с номером заявки
- Постерный футер: гигантский wordmark, уходящий за нижний край
- Зернистость SVG-noise 4%, все кинематографические эффекты отключаются при prefers-reduced-motion

## Стек

HTML5 + CSS3 (кастомные свойства — токены DESIGN.md) + Vanilla JS. Зависимостей нет. Внешние ресурсы: Google Fonts (Inter, JetBrains Mono) и фото Unsplash.
