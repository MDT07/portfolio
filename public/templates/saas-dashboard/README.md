# Шаблон «METRIC — SaaS-дашборд аналитики»

Демонстрационная панель продуктовой аналитики «METRIC». Уровень Linear/Vercel: data-dense UI без визуального шума.

## Запуск

Открыть `index.html` в браузере. Никакой сборки не требуется — один самодостаточный файл.

## Что внутри

1. **Sidebar** (240px, сворачиваемый) — лого, навигация (Обзор, События, Воронки, Retention, Отчёты, Настройки), карточка пользователя; состояние сохраняется в localStorage
2. **Topbar** — заголовок страницы, переключатель периода 7д/30д/90д, поиск, аватар
3. **KPI ×4** — MAU, DAU/MAU, Конверсия, Churn: animated counters при загрузке, дельты (зелёные/красные), SVG-спарклайны
4. **Главный график** — SVG area/line chart из JS-массива, сетка и оси, hover-crosshair с тултипом, переключатель метрик (Пользователи/Сессии/События) с morph-анимацией
5. **Таблица «Топ событий»** — 10 строк, сортировка кликом по заголовку (asc/desc со стрелкой), бары доли
6. **Воронка** — 4 ступени с процентами и конверсиями между шагами
7. **Система** — статусы API / CDN / Database: цветные точки, uptime, latency

## Интерактив (vanilla JS)

- Animated counters (requestAnimationFrame, easeOutCubic)
- SVG-график с crosshair-тултипом и morph-перерисовкой при смене метрики
- Переключатель периода — новые данные (7/30/90 точек)
- Live-обновления: раз в 5 с новая точка с плавным сдвигом окна (пауза на скрытой вкладке)
- Сортировка таблицы, сворачивание сайдбара (сохранение в localStorage)
- Счётчик «обновлено N сек назад» в футере

## Данные

Детерминированный ГПСЧ (mulberry32) с weekly-сезонностью и трендом — при каждом открытии графики одинаково красивые. Live-тики продолжают ту же seeded-последовательность.

## Стиль

Строго по `DESIGN.md`: монохром (#0A0A0A / #111111 / #1A1A1A / #242424), один акцент #0070F3, статусы только для дельт и индикаторов, Inter + JetBrains Mono, радиусы 6/8px, бордеры 1px, без градиентов и цветных теней. Числа выровнены по табуляции (`font-variant-numeric: tabular-nums`).
