# NORDE «Архив» — дизайн-спека редизайна (Awwwards-уровень)

Дата: 2026-07-31 · Статус: утверждено пользователем (все 5 секций)
Объект: `templates/ecommerce/index.html` (+ копия `public/templates/ecommerce/`)
Референс-банк: `docs/research/norde-redesign-references.md`

## 1. Контекст и цель

Текущий шаблон — самодостаточный vanilla-JS магазин (1504 строки): рабочие корзина, quick-view, фильтры, 8 товаров, strict-realism (тёмная тема, Inter/JBM, #0070F3). Моушн — только fade-up reveal. Уровень «корпоративный каталог».

Цель — тотальный редизайн до уровня Awwwards SOTD/HM: живой, подвижный, креативный сайт с кинематографикой, камерой и характером, при полном сохранении e-commerce функциональности.

## 2. Решения интервью (утверждено)

| Вопрос | Решение |
|---|---|
| Концепция | **Editorial Archive** — магазин как кураторский архив-издание (The Cloister + KM20) |
| Палитра | **Тёплая бумага + чернила**: `#FAFAF9` / `#1C1917` / металлик `#A16207`; 1–2 тёмные инверсии |
| Display-гарнитура | **Playfair Display** (кириллица, variable 400–900) |
| Кинематографика | 2D-кинематографика везде + **одна 3D-глава** (Three.js scroll-камера вокруг glTF-обуви) |
| Живой интерактив | **Горизонтальный лукбук-дрейф** (только он; cursor-эффекты/deck/геймификация — нет) |
| Структура | **Главы-истории, каталог внутри**; выдуманный лор разрешён |

## 3. Карта глав

- **00 Обложка** — hero: Playfair «Одежда без лишнего шума» (word-mask reveal), mono-шапка «NORDE · Архив · Выпуск 01», hero-фото clip-reveal, скролл-индикатор.
- **01 Манифест** — 3–4 принципа, раскрытие по скроллу, mono-маргиналии.
- **02 Лукбук** *(тёмная инверсия)* — pinned горизонтальный дрейф 6 образов «Look n°1…6», velocity-skew ≤ 4°, прогресс-линейка, «Образ в корзину» у каждого лука.
- **03 Planche** *(тёмная инверсия)* — pinned Three.js: камера огибает glTF-обувь, 4 ракурса с mono-подписями, 3 цветовых варианта, mono-спецификации.
- **04 Архив единиц** — каталог 8 товаров «Unit n°041–048», рубрикаторы-фильтры, quick-view-planche, корзина-drawer.
- **05 Условия архива** — преимущества editorial-таблицей (без иконок).
- **Финал** — постерный футер: clipped wordmark «NORDE», колонки ссылок, mono-подпись.

Сквозное: chapter-маркеры «00–05», архивная нумерация, captions «Planche n°2 — Кеды Court Low», hairline-разделители, Lenis-скролл, SVG-noise ≤ 0.05.

## 4. Визуальная система

### Палитра (CSS-переменные)

`paper #FAFAF9` (фон), `paper-2 #F4F3F1` (карточки), `ink #1C1917` (текст), `ink-2 rgba(28,25,23,.62)`, `ink-3 rgba(28,25,23,.38)`, `line #D6D3D1` (бордеры вместо теней), `brass #A16207` (единственный акцент: цены-метки, индексы, CTA, focus; на paper контраст 4.6:1 ✓ AA), `dark #161412` (фон инверсий), `dark-ink #EDE9E4`. Семантика: `error #DC2626` только для корзины/удаления.

Запрещено: градиенты, декоративные тени, скругления > 4px, глассморфизм, blob-формы, градиентный текст, typewriter, autoplay-видео, AI-иллюстрации.

### Типографика

- **Playfair Display** (кириллица) — hero `clamp(3rem, 9vw, 8rem)`, главы `clamp(2rem, 5vw, 4rem)`, lh 0.95–1.1; wordmark, цены quick-view.
- **Manrope** (кириллица) — UI/текст 15–17px, lh 1.6.
- **JetBrains Mono** — индексы, инвентарные номера, captions, цены в сетке: 11–12px, uppercase, tracking 0.06em.

Uppercase — только mono-метки и обложка. Заголовки глав — sentence case.

### Сетка

Контейнер 1360px, 12 колонок; архивная асимметрия (заголовок 5 кол. + маргиналии 2 кол.); поля между главами 120–160px; зерно SVG-noise ≤ 0.05 fixed, pointer-events: none. Фото — Unsplash, курация под тёплую палитру.

## 5. Кинематографика (GSAP + ScrollTrigger + Lenis)

- Ритм: микро 150–300ms; кинематографика 800–1100ms, `cubic-bezier(0.65, 0, 0.35, 1)`; только transform/opacity/clip-path.
- **Preloader** — раз за сессию: 0→100 mono, занавес вверх, проявление обложки.
- **Переходы глав** — curtain-wipe панелями (цвет = следующая глава).
- **Заголовки** — line/word-mask reveal, stagger 60–90ms, `aria-label` на полном тексте.
- **Фото** — clip-reveal `inset(100% 0 0 0)→inset(0)` + scale 1.12→1; в лукбуке лёгкий Ken Burns 20s.
- **FLIP-перелёт** товара из лукбука в слот каталога (один раз).
- **Velocity-marquee** mono-лента между главами.
- **Lenis** без джекинга (pinned только 02 и 03); `prefers-reduced-motion` глушит весь слой, контент виден сразу.

## 6. Глава 03 «Planche» (Three.js)

- Pinned ~300vh. Модель glTF-обуви Khronos (CDN, Draco ≤ 3 МБ); fallback — статичное фото при ошибке/отсутствии WebGL.
- **Камера:** 4 ракурса по скроллу (latérale → dessus → détail → 3/4), интерполяция позиции и цели, mono-подписи сменяются.
- **Варианты:** 3 swatch (material variants), cross-fade.
- **Спеки:** mono-таблица слева, построчное появление.
- Hover-drift ±3° (без свободного orbit). Лоадер «Chargement… %».
- Renderer — ленивая инициализация у главы, `powerPreference: high-performance`, dispose при reduced-motion.

## 7. Интерактив и e-commerce

- **Лукбук:** pinned ~400vh, scrub-дрейф 6 образов (transform-only); карточка лука = фото 4:5 + «Look n°» + mono-состав + «Образ в корзину» (2–3 товара разом).
- **Каталог:** те же 8 товаров/4 категории; карточка-картотека (hairline, mono-шапка, clip-reveal при появлении, hover scale 1.04 + «Quick view»).
- **Quick-view:** модалка-planche (фото clip-reveal, Playfair-название, mono-цена, описание ткани, размеры-chips, «В корзину»; Esc/overlay/фокус-ловушка).
- **Корзина-drawer:** как сейчас (+/−, удаление, доставка от 10 000 ₽, оформление) + подтверждение «Акт приёма n°…».
- **Toast:** «Unit n°043 → Корзина».
- Микро: underline-sweep на ссылках, focus-кольца brass. Курсор стандартный.
- A11y: контент читается без анимаций, клавиатура по всем сценариям, контрасты ≥ AA.

## 8. Техническая реализация

- Один `index.html` (CSS в `<style>`, JS в `<script type="module">` в конце) + синхронная копия в `public/templates/ecommerce/`.
- CDN (фиксированные версии): GSAP 3.12 + ScrollTrigger, Lenis 1.x, Three.js 0.16x (importmap + GLTFLoader + DRACOLoader), Google Fonts (cyrillic subsets).
- Офлайн/ошибка CDN → сайт без анимаций/3D, контент полностью читаем (прогрессивное улучшение).
- Данные товаров/образов — JS-массивы в файле.
- Бюджет: LCP < 2.5s, Lighthouse Perf ≥ 90, A11y ≥ 95; rAF-циклы спят вне вьюпорта; `content-visibility: auto` на каталоге; lazy-фото кроме hero.

## 9. Проверки перед сдачей

- Полный цикл магазина: фильтры → quick-view → размер → корзина → +/− → удаление → оформление → «Акт приёма».
- CDP-скриншоты: все главы, обе инверсии, 390px мобильный, `prefers-reduced-motion`; консоль чистая.
- Клавиатурный прогон всех сценариев; focus виден везде.
- `scripts/validate-case.mjs` — если применим к шаблонам.

## 10. YAGNI (не делаем)

Cursor trail, deck-of-cards, геймификация «Собери комплект», WebGL-текст, видео-фоны, свайп-жесты корзины, PWA, бэкенд оплаты, свободный orbit в 3D, больше двух тёмных инверсий.
