# NORDE «Архив оживает» — дизайн-спека

Дата: 2026-08-01 · Статус: утверждена концепция (полный объём) · Источник концепции: консультация Hermes CLI (kimi-k3) + граф знаний (ui-ux-pro-max: horizontal-scroll-journey, storytelling-driven, editorial-grid)

## 1. Контекст и цели

Шаблон `templates/ecommerce/index.html` (один самодостаточный файл, CSS/JS инлайн, CDN: Lenis, GSAP+ScrollTrigger) после апгрейда Editorial+ выглядит строго. Владелец заказал: убрать 3D из главы 03, переделать главы 02 и 04, добавить цвета, контента и 2D-интерактива, превратить витрину-бутик в контент-платформу уровня Awwwards.

Цели:
- Глава 03 — продуктовая 2D-сцена вместо Three.js.
- Глава 02 — образы читаются целиком + детальный просмотр каждого образа.
- Глава 04 — больше контента/интерактива + исправление бага «бесконечного зума» при hover.
- Глобально — цветные главы, новые секции контента, моушн-пакет 2D-техник.
- Сохранить: архив-издание (бумага/чернила/латунь), e-commerce ядро (корзина, акт), QA-харнесс, reduced-motion fallback, перф (LCP < 2.5с локально).

## 2. Жёсткие ограничения

- Один `index.html`, без сборки. Библиотеки только по CDN: Lenis, GSAP (+ScrollTrigger, +Flip — свободный плагин из той же dist). Three.js и import map удаляются полностью.
- Фото — Unsplash. Копирайт — русский.
- Весь моушн — только `transform/opacity/clip-path/filter` + CSS-переменные цвета.
- `prefers-reduced-motion`: Lenis/ScrollTrigger/Flip не инициализируются, все финальные состояния видны статично.
- Публичная витрина `public/templates/ecommerce/` синхронизируется в конце.

## 3. Дизайн-система: цветные главы («пигменты архива»)

Латунь `#A16207` — сквозной мета-цвет: индексы, ссылки, цены, корзина, все интерактивные состояния покупки (покупка не распадается по цветам).

Каждая глава получает приглушённый скандинавский пигмент (палитра «Нордик») — как цветная вкладка архивной папки:

| Глава | Пигмент | На тёмном фоне |
|---|---|---|
| 00 Обложка | латунь (база) | — |
| 01 Манифест | хвоя `#3F6212` | — |
| 02 Лукбук (тёмная) | ягода `#9F1239` | rose `#FB7185` (декор) |
| 03 Planche (тёмная) | море `#155E75` | cyan `#67E8F9` (декор) |
| Прил. А Материалы | мох `#4D7C0F` | — |
| 04 Каталог | терракота `#9A3412` | — |
| Прил. Б Журнал | сланец `#475569` | — |
| 05 Условия + Клуб | латунь (база) | — |

Механика: CSS-переменная `--chapter-accent` на `<html>`; каждая глава задаёт свой пигмент через `data-accent`, GSAP scrub-твин переливает переменную на границах глав (совместно с curtain-wipe, см. §8). Пигмент применяется точечно: индекс главы, заголовочное слово-курсив, нумерал, активные фильтры, прогресс-линии. Тёмные главы используют осветлённый декор-вариант. Reduced-motion: пигмент меняется дискретно на границе.

Контраст: пигменты только для крупного текста/декора (≥ 4.5 для крупного на бумаге); основной текст — чернила.

## 4. Глава 02 — Лукбук

### 4.1 Компоновка ленты (фикс «видно половины»)

- `.look` — `flex:0 0 auto`; медиа: `height:min(72vh,780px); aspect-ratio:3/4; width:auto` — портретный кадр всегда целиком по вертикали.
- Ритм разворота: воздух 8–12vw между образами; между ними текстовые интерлюдии (номер лука, состав mono-строкой) — лента читается как журнальный разворот, не конвейер.
- Пин и scrub 0.6 + anticipatePin сохраняются; skew по скорости сохраняется.

### 4.2 Детальный просмотр (pinned detail-стейдж)

- Клик по образу (или кнопка «Смотреть образ»): лента встаёт на паузу (Lenis `stop()`), выбранный образ **FLIP-переездом** (GSAP Flip) занимает левые ~55% экрана, справа выезжает панель: название образа, состав (вещи с инвентарными номерами и ценами), кнопка «+» у каждой вещи и «Образ в корзину» целиком.
- Закрытие: Esc, клик по фону, кнопка × — обратный FLIP в ленту, Lenis `start()`.
- Панель — часть DOM главы 02 (не fixed-модалка поверх пина), чтобы не конфликтовать со ScrollTrigger-пином: стейдж — overlay внутри pinned-секции (`position:absolute; inset:0` внутри главы).
- Fallback без Flip (CDN не загрузился / reduced-motion): стейдж открывается мгновенно (класс `.no-motion`), без перелёта.
- Кастомный курсор с подписью «смотреть образ» над образами (desktop, pointer:fine).

### 4.3 Контент

6 образов: Город, Студия, Дом, Путь, Вечер, Утро (шестой — новый, с фото и составом). У каждого: название, настроение, состав 2–3 вещи из каталога (реальные id PRODUCT'ов — кнопки реально кладут в корзину).

## 5. Глава 03 — Planche без 3D: двухактная сцена

Three.js, import map, GLB-загрузчик, hover-drift, canvas — удаляются полностью (включая fallback-фото логику сцены).

### Акт 1 — Exploded-анатомия NR-0202 (pinned)

- Сцена pinned на ~250–300vh. Центр — 4 вертикально стекнутые фото-плашки (Unsplash крупные планы: текстиль верха, подошва/пена, шнуровка/люверсы, стелька/внутренность), каждая в своей `clip-path` маске.
- По скроллу плашки разъезжаются по Y с разной скоростью (scrub), между ними проявляются mono-подписи спек с линиями-выносками: «Верх — переработанный текстиль», «Подошва — пена EVA», «Вес — 290 г», «Артикул — NR-0202».
- Цифры спек — scramble-перебор при входе (290, % переработки).
- Финал акта: плашки собираются обратно в цельное фото (мост к акту 2).

### Акт 2 — Студия цвета

- Крупное фото кроссовка; 3 свотча колорвеев: «Море» (синий), «Песок» (песочный), «Графит» (почти чёрный). Переключение — crossfade трёх реальных фото (не CSS-тинт), фон секции плавно переливается в цвет колорвея (GSAP color-tween фона), имя колорвея + scramble-цифры спек.
- Свотчи доступны с клавиатуры (кнопки, `aria-pressed`).

### Контент

Спеки (уже есть): текстиль / EVA / 290 г / NR-0202. Добавить: % переработанного материала, сезон, короткая строка-признание («Единственный образец выпуска с…»). CTA «В корзину» (кроссовок = существующий товар каталога).

## 6. Глава 04 — Каталог

### 6.1 Фикс «бесконечного зума»

Диагноз: `.product:hover{transform:translateY(-4px)}` выводит карточку из-под курсора → hover теряется → карточка возвращается → цикл; плюс `transition: transform` на img конфликтует с любыми JS-твинами transform.

Фикс:
- Убрать `translateY(-4px)` с карточки.
- Zoom — один владелец: чистый CSS на img внутри `.product-media{overflow:hidden}`: `transition:transform .8s cubic-bezier(.22,1,.36,1)`, hover `scale(1.06)`. Никаких GSAP/JS-твинов transform на этом img.
- Поведение проверить кадрами и вручную (прогон QA + визуальный контроль).

### 6.2 Интерактив и контент

- Сортировки: релевантность (по умолчанию), цена ↑, цена ↓, новизна. Переключатель mono-строкой рядом с фильтрами. Перестановка — FLIP (`Flip.from` с autoAlpha + stagger 30ms); без Flip — мгновенно.
- Насыщенные карточки: инвентарный № (есть), материал («переработанный хлопок» и т.п.), 2–3 точки колорвеев, бейдж «осталось N» на дефиците (поле `stock` в PRODUCTS).
- «+ в корзину» одним кликом с карточки (размер по умолчанию — первый доступный) с микро-анимацией перелёта точки в счётчик корзины.
- Quick-view: добавить второе фото (поле `img2`) и список материалов.
- Счётчик «показано N из 8»; строка-итог после сетки: «Все единицы производятся малыми партиями…».

## 7. Новые секции (платформа)

Нумерация глав 00–05 не меняется (не ломаем QA и якоря). Новые секции — **приложения архива**: «Прил. А — Материалы» и «Прил. Б — Журнал» с буквенными нумералами (А/Б) в стиле `.chapter-numeral`. Клуб — внутри главы 05.

### 7.1 «Материалы» (Прил. А, между 03 и 04)

Библиотека тканей: горизонтальная лента 4 карточек-образцов (макро-фото, название, состав, происхождение, «используется в: NR-0202»). Свой пигмент (мох). Карточка — крупный тактильный образец с clip-reveal; hover — фото «проявляется» в цвет. Без пина (обычный горизонтальный скролл-ряд с drag на тач).

### 7.2 «Журнал» (Прил. Б, между 04 и 05)

3 статьи-разворота (гид по стилю, уход за вещами, как производим): editorial-вёрстка (крупный заголовок, дата/рубрика mono, первый абзац инлайн, фото), «Читать» → разворот на весь экран (overlay в потоке, Lenis stop, Esc закрывает). Полные тексты 3–5 абзацев — реальный контент, не lorem.

### 7.3 «Архивный клуб» (в главе 05 перед футером)

Подписка: early access к дропам. Одно поле email + кнопка-автомат: idle → «отправляем…» → «Вы в списке — № 128» (номер — псевдо-случайный, без бэкенда; состояние хранится в sessionStorage). Валидация email, ошибка — красная mono-строка.

## 8. Моушн-система (2D-техники → применение)

1. **Word-mask reveal** заголовков (есть) — все главы, включая новые.
2. **Clip-path reveal** медиа (есть) — новые секции тоже; старт `top 90%`.
3. **Velocity-marquee** — ленты-мосты между главами 02→03 и 04→Прил. Б («NORDE — АРХИВ — SS26 —»), скорость от скорости скролла (есть движок marquee).
4. **Scramble-перебор** цифр — спеки 03, счётчики каталога, номер в клубе.
5. **Magnetic-кнопки** (притяжение ≤ 8px в радиусе 60px, spring-возврат) — «В корзину», «Оформить», кнопка клуба. Только pointer:fine.
6. **Кастомный курсор** с контекстной подписью («смотреть образ», «+ просмотр») — лукбук и каталог; pointer:fine, отключается на touch; нативный курсор остаётся видимым (не прячем — доступность).
7. **Pinned scrub-композиции** — exploded-анатомия 03; лёгкий параллакс фото обложки (y + scale по скроллу).
8. **Curtain-wipe в пигменте главы** — существующие wipe-панели красятся в `--chapter-accent` следующей главы (сейчас монохромные).
9. **Grayscale→color «проявление»** — расширить дуотон-поведение: фото новых секций входят в вьюпорт в дуотоне и проявляются в цвет по scroll-прогрессу (не только по hover).

Reduced-motion: всё выше отключено, состояния финальные и статичные.

## 9. Доступность и перф

- `prefers-reduced-motion` — как в §2/§8; новые чеки в QA.
- Клавиатура: свотчи, detail-стейдж (Esc), журнал-оверлей (Esc, focus-trap не требуется — фокус возвращается на кнопку «Читать»), сортировки — нативные кнопки.
- `aria-pressed` на свотчах/сортировках, `aria-live` на счётчике «показано N из 8» и корзине (уже есть).
- Изображения: eager+preload только первые 2 образа лукбука и фото студии цвета (видны в пинах); остальные новые — `loading="lazy"`. LCP-спотчек в конце (< 2.5с).
- Кастомный курсор и magnetic — только `pointer:fine`.
