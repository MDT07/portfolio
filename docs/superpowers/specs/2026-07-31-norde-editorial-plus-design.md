# NORDE «Архив» — апгрейд Editorial+ (дизайн-спека)

Дата: 2026-07-31 · Статус: утверждено пользователем · Подход: A (Editorial+)
База: `templates/ecommerce/index.html` (после редизайна «Архив», коммит cf467d6)
Исходные решения пользователя: полный апгрейд · архивный дуотон · копирайт под модель · подход A.

## 0. Проблемы, которые закрываем (из визуального аудита)

1. «Элементы пропадают»: 6 образов лукбука с `loading="lazy"` догружаются во время pinned-дрейфа; карточки каталога ревилятся без rootMargin — поздно.
2. Скролл «ватный»: Lenis `lerp:0.11` + `scrub:1` на пинах = двойное сглаживание; нет `anticipatePin`.
3. 3D-модель (синий тканевый кроссовок Khronos) не соответствует копирайту («Кеды Court Low, верх — телятина»).
4. Фото разнородны по цветокоррекции — визуальный шум.
5. Границы-волосы (`border-top` глав, рамки медиаблоков) дают «табличный» примитивный вид.
6. Hero — пустая правая половина первой ширмы, фото под фолдом.
7. Манифест — плоский текст без editorial-приёмов.

## 1. Дизайн-система

### Borderless
- Убрать `border-top` у `.chapter` (и `border-top-color` у dark), рамки у `.hero-media`, `.look-media`, `#plancheStage`, `.product-media`, `.footer` / `.footer-cols`.
- Разделение глав — воздухом: ритм вертикальных паддингов 160px (desktop) / 96px (≤720px) и сменой тона paper↔ink.
- Линии остаются только: таблица `.terms` (формуляр — уместно), функциональные панели (drawer, modal, toast, cart-item разделители), `.lookbook-progress` (функциональный индикатор, тонкий brass).

### Дуотон-система
- Единый класс-обработчик: фото `filter: grayscale(1) sepia(.22) contrast(1.06) brightness(1.02)`; в тёмных главах `brightness(.95)`.
- Hover на `.look` и `.product` — плавное проявление цвета (`filter: none`, transition .6s var(--ease-cine)).
- Применяется ко всем `<img>` контента: hero, лукбук, каталог, quick-view, planche-fallback, корзина-миниатюры (в корзине — дуотон без hover).
- `prefers-reduced-motion`: дуотон остаётся (это не движение), hover-проявление — мгновенное (transitions отключены глобальным RM-правилом).

### Графика нумералов
- В каждой главе — фоновый нумерал (Playfair Display 900, `clamp(8rem,18vw,16rem)`, `position:absolute`, вне потока): opacity .05 на светлом, .07 на тёмном, `pointer-events:none`, `aria-hidden`.
- Мобильная: `clamp(5rem,22vw,8rem)`, прижат к правому краю, не пересекается с текстом (z-index под контентом).

## 2. Глава 00 — Обложка (100svh)

- Сетка: фото — правые ~55% ширины во всю высоту ширмы (object-fit cover, clip-reveal снизу существующим механизмом `[data-clip]`).
- Левый край фото: напыление `linear-gradient(90deg, var(--paper) 0%, transparent 45%)` поверх (::after) — заголовок заходит на фото и читается везде.
- Заголовок (существующий mask-reveal по словам) — крупно слева, перекрывает фото на ~10–15%.
- Мета «Архив · Выпуск 01 · Осень 2026» — вертикально (`writing-mode:vertical-rl`) вдоль правого края ширмы, mono 11px, letter-spacing .18em.
- «Листайте ↓» — слева внизу, без изменений по стилю.
- Мобильная: фото — нижние 42% ширмы во всю ширину, напыление сверху, заголовок сверху; вертикальная мета скрывается.

## 3. Глава 01 — Манифест-разворот

- Сетка 12 колонок: заголовок col 1–5; правила — col 7–12.
- Правила двумя колонками (2×2), каждое: латунный нумерал «П. 1.1» крупно (Playfair, 28px) + текст; разделение воздухом (gap 56px), без hairline.
- Pull-quote: «Материалы важнее логотипов» — col 6–12 отдельной строкой, Playfair italic clamp(2rem,4vw,3.4rem), brass; убирается из списка правил (остаются 1.1, 1.2, 1.4 → нумерация в тексте корректируется: П. 1.1, П. 1.2, П. 1.3).
- Drop cap у первого правила (::first-letter, Playfair 3.2em, brass, float left).
- Мобильная: одна колонка, pull-quote между заголовком и правилами.

## 4. Глава 02 — Лукбук

- Все 6 образов `loading="eager"` + `<link rel="preload" as="image">` первых трёх (уничтожает догрузку в пине).
- Карточки крупнее: `flex-basis min(62vw,640px)` (мобильная 78vw — без изменений), `gap 48px`.
- Дуотон + hover-проявление; caption (состав + «Образ в корзину») без изменений по логике.
- Пин: `anticipatePin:1`, `scrub:0.6` (было 1).

## 5. Глава 03 — Planche (честный)

- Продукт переименован под реальную модель: **«Archive Runner»**; заголовок: «Archive Runner в четырёх ракурсах».
- Спеки переписаны: Верх — переработанный текстиль; Подошва — пена EVA; Вес — 290 г; Артикул — NR-0202.
- Свотчи → 3 реальных варианта `KHR_materials_variants` модели: имена вариантов читаются из загруженного GLTF (не хардкод), цвет свотча — приближение, подпись-лейбл = имя варианта (mono, рядом при наведении/активности).
- Модель крупнее: нормализация bbox → 2.0 (было 1.6); сцена без рамки (`border` убран из `#plancheStage`); fallback-фото — дуотон.
- Пин: `anticipatePin:1`, `scrub:0.6`.
- QA-чеки с текстами спек/свотчей обновить под новый копирайт («4 ракурса», «3 swatch», «сцена: canvas или fallback» — без изменений).

## 6. Глава 04 — Каталог

- Сетка без `gap:1px` и рамок: `gap:32px`, фон сетки прозрачный; карточки без фона-ховера — вместо этого: фото дуотон, hover — проявление цвета + `translateY(-4px)` у карточки (transition .35s var(--ease-cine)).
- Clip-reveal раньше: IntersectionObserver на `.product` с `rootMargin:'0px 0px 200px 0px'` (сейчас 0) — карточки готовы до входа во вьюпорт.
- FLIP-перелёт 02→04 сохраняется; клону при перелёте инлайнится тот же дуотон-фильтр, чтобы не лететь цветным в дуотон-карточку.
- Фильтры-рубрики: кнопки без рамок — текст mono с подчёрком-точкой у активного (border убираем, активный — brass + dot).

## 7. Глава 05 + футер

- `.terms` — единственное место с линиями (оставляем: формуляр).
- Футер: убрать `border-top` у `.footer` и `.footer-cols`; wordmark и колонки без изменений.

## 8. Скролл и техника

- Lenis: попробовать `lerp:0.12`; если всё ещё ватно — `duration:1.05, easing:(t)=>1-Math.pow(1-t,3)`. Решение фиксируется после визуальной проверки в живом браузере. `smoothWheel:true` (дефолт).
- ScrollTrigger: `anticipatePin:1` на обоих пинах; `scrub:0.6`; `ScrollTrigger.config({ignoreMobileResize:true})`.
- `[data-clip]` ревилы: start `'top 90%'` (было 85%).
- Hero-фото: `fetchpriority="high"` сохраняется + дуотон.
