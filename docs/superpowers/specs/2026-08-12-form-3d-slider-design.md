2026-08-12

## Цель
Заменить текстовые карточки в секции «Галерея — Проекты в 3D» на визуальные SVG-макеты зданий в wireframe-стиле.

## Текущее состояние
- 3D-слайдер в `templates/form/index.html` строки 520–564
- 6 слайдов с текстом: номер, название, мета-данные
- Размер карточки: 280×200 px
- CSS: строки 159–169

## Новая архитектура

### Размеры
- Карточка `.slide-3d`: 320×280 px (было 280×200)
- SVG: viewBox="0 0 200 160", размер в карточке ~200×160 px
- Padding карточки: 20px

### SVG-макеты (inline, stroke-only)

#### 1. Музей «Платформа»
- Промышленный корпус с плоской крышей
- Большие окна-рамы (сетка 4×3)
- Навес на колоннах справа
- Труба слева
- Группы линий: корпус → окна → навес → труба

#### 2. «Северный парк»
- Три секции разной высоты (9, 12, 17 этажей условно)
- Поднятый двор-парк в центре (нижний уровень)
- Лоджии на фасадах (горизонтальные линии)
- Группы: левая секция → центральная → правая → двор

#### 3. Вокзал «Южный»
- Волнообразная скатная крыша
- Сквозной просвет (высокий центр)
- Терраса-амфитеатр справа (ступеньки)
- Группы: крыша → фасад → просвет → терраса

#### 4. «Терминал»
- Высокая башня (прямоугольник)
- Внутренняя «улица» — атриум (вертикальный разрез)
- Переговорные-кубы выступают
- Группы: башня → атриум → кубы → основание

#### 5. «Старая гавань»
- Мастер-план: сетка кварталов
- Набережная — изогнутая линия снизу
- Три зоны: портовая, жилая, парковая
- Группы: сетка → набережная → зоны → дороги

#### 6. «Стрелка»
- Дом на сваях (вертикальные линии внизу)
- Два консольных вылета к воде
- Вода — волнистая линия снизу
- Группы: сваи → корпус → вылеты → вода

### Стиль
- stroke-width="1.2"
- stroke="currentColor" (наследует цвет текста)
- fill="none"
- Активный слайд: stroke → var(--accent) #FF4D00
- CSS transition: stroke 0.3s

### Анимация
- При активации: `stroke-dasharray` + `stroke-dashoffset` анимация
- Duration: 0.8s, easing: var(--ease-cine)
- Stagger: 0.12s между группами линий
- Класс `.drawn` добавляется JS при активации слайда

### CSS-изменения
```css
.slide-3d {
  width: 320px;
  height: 280px;
  padding: 20px;
  display: flex;
  flex-direction: column;
  align-items: center;
  justify-content: space-between;
}
.slide-3d svg {
  width: 200px;
  height: 160px;
  transition: transform 0.3s;
}
.slide-3d:hover svg {
  transform: scale(1.03);
}
.slide-3d svg path, .slide-3d svg line, .slide-3d svg rect {
  stroke-dasharray: 300;
  stroke-dashoffset: 300;
  transition: stroke-dashoffset 0.8s var(--ease-cine);
}
.slide-3d.active svg path, .slide-3d.active svg line, .slide-3d.active svg rect {
  stroke-dashoffset: 0;
}
.slide-3d.active svg {
  color: var(--accent);
}
```
