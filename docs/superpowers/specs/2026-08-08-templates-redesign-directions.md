# Направления тотального редизайна шаблонов портфолио (T3)

Дата: 2026-08-08. Статус: утверждено пользователем по итогам интервью (текстовый формат, без визуального компаньона — режим экономии токенов).
Основание: `docs/research/2026-08-08-web-design-ux-ui-2026.md` (T1), `docs/research/2026-08-08-tools-skills-audit.md` (T2), граф знаний (`design/hubs/trends-2026-hub`).

## Декомпозиция

Пять шаблонов — пять независимых подпроектов. Каждый получает свой цикл спека → план → реализация в задачах T4–T8. Этот документ фиксирует только выбранные направления и общие принципы; детальная спека — в своей задаче.

## Общие принципы (все шаблоны)

- **Уникальность архетипов**: ни один приём не повторяется между шаблонами в одинаковой форме (у каждого свой рендер-слой, своя типографика, своя палитра).
- **Перфоманс-бюджет** (из T1): LCP<1.5s, CLS<0.05, INP<100ms, <3MB, 60fps на mid-range. Бюджет — часть дизайна, не пост-оптимизация.
- **Доступность**: WCAG 2.2 AA; prefers-reduced-motion уважается везде; звук — только opt-in, выключен по умолчанию.
- **Анти-тренды под запретом**: видео-фоны, hero+текст, bento-сетки, blanding-минимализм, шаблонные AI-лейауты, scroll-hijacking на тексте, ghost buttons.
- **QA**: каждый шаблон получает/обновляет свой CDP-сьют по образцу qa-norde (чеки + скриншоты глав); FPS-зонд и LCP-спотчек обязательны.
- **Синк**: `templates/` ↔ `public/templates/` + README каждого шаблона.

## NORDE — «Живой архив» (эволюция)

- **Сохраняем**: инвентарную ведомость (глава 04), editorial-ДНК, бумажную базу, акт приёма, опись.
- **Добавляем**: процедурное зерно/текстура бумаги (feTurbulence/tsl-textures-уровень, без PNG-веса); кинетическую типографику заголовков глав (SplitText уже есть); звуковой слой opt-in (Howler, микро-звуки штампов/печати — `design/motion/ui-sound-design`); View Transitions между состояниями (`design/stacks/view-transitions-api`); CSS scroll-driven reveal там, где GSAP избыточен.
- **Цвет**: тихая бумажная база + один dopamine-акцент (кандидат: сигнальный красно-оранжевый или jewel-изумруд — выбор в T4).
- **Уходит**: излишняя однотонность; статичность глав без микро-интерактива.

## ATLAS — «Экспедиционный атлас»

- **Рендер-слой**: MapLibre 3D-рельеф (стек обкатан в PRIMARY TERRA); карта — сквозной слой страницы, не врезка.
- **Нарратив**: маршруты экспедиций дорисовываются по скроллу (анимированные линии/точки); главы = перелёты камеры между координатами; scroll-кинематограф без hijacking текста.
- **Типографика**: old-style serif (кандидаты: Brygada 1918 / Cormorant / EB Garamond из графа) + моно для координат и телеметрии.
- **Палитра**: картографическая бумага/песочная база + один акцент (сигнальный оранжевый экспедиций); штампы, печати, координатные сетки — micro-industrial слой.
- **Сет-писы**: hero — глобус/рельеф с медленным дрейфом; журнал экспедиций как полевые записи; смета снаряжения.

## FORM — «Чертёжная мастерская»

- **Визуальный язык**: планшетная графика — тонкая линия, выноски, аннотации, размерные линии; сетка чертежа как композиционная основа.
- **Моушн-подпись**: планы чертят себя по скроллу (SVG stroke-dash хореография, scrub); сечения и фасады собираются из линий.
- **Типографика**: Unbounded (есть) для дисплея + моно для аннотаций; exaggerated hierarchy (гигантский кегль + микро-аннотации).
- **Палитра**: белый/глина + латунь (brass уже в ДНК FORM); синяя чертёжная как возможный второй акцент — решение в T6.
- **Сет-писы**: проект раскрывается как лист альбома (план → фасад → сечение → фото); курсор-рейсфедера на pointer:fine.

## AI WORKS — «Мануфактура интеллекта»

- **Контр-клише**: AI-компания в эстетике мануфактуры XIX–XX века — тёплая бумага, гравюры, схемы машинного века, штампованные спецификации. Никакого dark-neon.
- **Типографика**: old-style serif для манифеста (Garamond-класс) + моно для «патентных» спецификаций; кинетика заголовков — печатный станок (буквы «вбиваются»).
- **Палитра**: бумага/сепия + чернильный + один акцент (медь/латунь или сигнальная киноварь — решение в T7).
- **Моушн-подпись**: механика — шестерни/риггели как SVG-механизмы, «патентные» схемы анимируются по скроллу; текстуры — гравюрный штрих (генерация, не PNG).
- **Сет-писы**: продукты как «машины» с патентными листами; демо-блок AI как «испытательный стенд» (живой интерактив, но в механической раме).
- **Анти-AI-slop**: визуалы с человеческим следом (гравюрная стилизация), ноль стокового «нейро-глянца».

## VOLT — «Пульт сети»

- **Рендер-слой**: тёмная карта зарядной сети (MapLibre dark), живое ощущение пульта диспетчера.
- **Моушн-подпись**: потоки энергии бегут по маршрутам (анимированные линии/партиклы); пульс активных станций; телеметрия обновляется «вживую» (симуляция на клиенте).
- **Типографика**: Tektur (есть) для телеметрии и дисплея + нейтральный гротеск для текста; micro-industrial техтекст.
- **Палитра**: глубокий dark (не чёрный) + вольт-зелёный/электрик как единственный светящийся акцент (кинематографичный dark mode из T1).
- **Сет-писы**: hero — карта сети с дыханием станций; тарифы как панели приборов; статистика сети — живые счётчики.
- **Отличие от ATLAS**: у ATLAS — бумажная карта и перелёты камеры, у VOLT — тёмный пульт и потоки; MapLibre общий, язык разный.
