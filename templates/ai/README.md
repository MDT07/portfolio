# AI WORKS — лендинг раздела AI-работ

Awwwards-ориентированный демо-лендинг студийного направления AI-интеграций.
Один самодостаточный файл `index.html` — без сборки и зависимостей, открывается напрямую (file://) или любым статик-сервером.

## Стиль

Яркий multi-accent (исключение из монохрома портфолио — сознательное): глубокий тёмный фон `#08080F`,
живая aurora из размытых блобов, glassmorphism-панели, зерно. Manrope (кириллица) + Onest + JetBrains Mono.
Фишка: **выбор AI-ядра перекрашивает всю страницу** — CSS-переменные --acc/--acc2 меняются под бренд-цвета ядра.

## Структура

- **Hero** — градиентный заголовок, переключатель «ядро страницы» (6 ядер), 4 count-up метрики
- **Живое демо** — конструктор ассистента: ядро (GPT-5 / Gemini 2.5 / Claude 4 / Llama 3.3 / GigaChat / YandexGPT) × роль (продажи/поддержка/HR) × канал (веб/Telegram/WhatsApp). Чат пересобирается: своя задержка, стиль ответов, скин канала; стриминг текста, typing-индикатор, подсказки; локальный intent-движок
- **Кейсы** — 6 карточек с мини-презентациями: моки TG-чата, веб-виджета, WhatsApp, waveform звонка со скорингом, HR-пайплайн, голос
- **Ядра** — сравнительная таблица (скорость/качество/цена, анимированные бары) + пикер приоритета с рекомендацией
- **Процесс** — анимированный SVG-пайплайн (бегущая точка по animateMotion) + 4 шага
- **Пакеты** — Пилот / Бизнес / Enterprise
- **FAQ** — безопасность, 152-ФЗ, локальные модели
- **CTA** — форма с валидацией (email/телефон/@telegram)

## Интерактив (vanilla JS)

- Переключение ядра перекрашивает страницу и меняет поведение чата (latency, стиль, скин)
- Стриминг-чат с локальной базой знаний (8 интентов × flavor по ядру)
- Анимированные бары сравнения, count-up метрики, animateMotion-пайплайн
- Аккордеон FAQ, валидация CTA, reveal-анимации

## QA

`python3 scripts/qa-template.py ai [--mobile] [--shot]` — 21 ассерт: бут, переключение ядер (акцент страницы), чат (подсказки, ввод, скины каналов), пикер рекомендаций, счётчики, аккордеон, валидация, overflow.
