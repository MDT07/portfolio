# Шаблон «NORDE Архив» — editorial-магазин

Демонстрационная витрина скандинавского магазина одежды и предметов дома, поданная как **архив-издание**: бумага, чернила, латунь, нумерованные главы. Полностью самодостаточный `index.html` — CSS и JS встроены, внешние библиотеки подключены по CDN.

Уровень **Awwwards-ориентированный Editorial+**: borderless-сетка (главы текут без видимых границ), **дуотон-система** фото — базовая архивная `grayscale(1) sepia(…)` + свои тонировки у приложений (moss у Материалов, steel у Журнала, тёплая у лукбука), крупные нумералы глав на полях. Концепция «Архив оживает»: у каждой главы свой **пигмент** (data-accent), который окрашивает нумерал, метки и интерактив, а в приложениях фото проявляются из дуотона в цвет.

## Запуск

Открыть `index.html` в браузере — сборка и сервер не требуются.

```bash
open index.html        # macOS
# или просто двойной клик по файлу
```

## Главы

- **00 / Обложка** — обложка во весь экран (100svh): фото коллекции справа с paper-напылением, параллакс медиа при скролле, вертикальная мета выпуска; маска-ревил заголовка по словам. Мобила: фото нижние 44svh
- **01 / Манифест** — журнальный разворот на 12 колонок: pull-quote курсивом в пигменте главы, drop cap, пункты П.1.1–1.3
- **02 / Лукбук** *(тёмная)* — pinned горизонтальный дрейф шести образов: кадр 3:4, интерлюдии-развороты между образами, прогресс-линия, skew по скорости; клик по образу открывает **detail-стейдж** (ручной FLIP-перелёт клона, состав образа, Esc/focus-return); «Образ в корзину» добавляет комплект
- **03 / Planche** *(тёмная, двухактная 2D-сцена, без Three.js)* — акт I «Анатомия»: слоистая planche Archive Runner с выносками, собирающимися по скроллу (scrub); акт II «Студия цвета»: свотчи перекрашивают сцену пигментом, scramble-подписи
- **04 / Архив единиц** — картотека из 8 единиц: текстовые фильтры-рубрики с точкой у активной, **сортировки** (как в архиве / цена ↑↓ / новизна) с aria-live счётчиком «показано N из 8» и scramble цен при перестановке, насыщенные карточки (остаток, unit-номер, рубрика); зум убран структурно — вместо scale **кроссфейд на второй кадр товара** при наведении, quick-view; при входе в главу образ из 02 «перелетает» в первую карточку (FLIP, клон с дуотоном)
- **Прил. А / Материалы** — из чего сделан архив: карточки волокон с происхождением, moss-дуотон; **полосы состава** (87% переработано, 240 г/м²…) дорисовываются при входе; на pointer:fine — лупа цвета
- **Прил. Б / Журнал** — записки архивариуса: три эссе с датами и рубриками, steel-дуотон, проявление в цвет при входе
- **05 / Условия архива + Архивный клуб** — доставка/возврат/гарантия/оплата табличной вёрсткой (scramble нумеров У.5.x, hover-подсветка строк); клуб — форма записи на пополнение (sessionStorage, номер в списке, scramble-подтверждение, штамп)
- **Футер** — постерный wordmark NORDE во всю ширину + колонки ссылок

## E-commerce ядро

Каталог, фильтрация, сортировки, quick-view модалка (выбор размера, Esc закрывает), detail-стейдж образов, корзина-drawer с количеством/удалением/доставкой (бесплатно от 10 000 ₽) и оформлением в **Акт приёма** с номером и составом. Счётчик в шапке, toast-уведомления.

## Motion-стек (CDN)

Только **GSAP + Lenis** — никакого WebGL:

- **Lenis** — плавный скролл (lerp 0.12), velocity-marquee реагирует на скорость
- **GSAP + ScrollTrigger** — прелоадер-счётчик (первый визит сессии), маски заголовков, pull-quote манифеста проявляется по словам от скролла (scrub), curtain-wipe с пигментом главы, пин 02 (двухскоростной дрейф: подписи и интерлюдии в противофазе + scramble-счётчик образа «01/06»), scrub-сборка анатомии, FLIP-перелёты, scramble-текст; `ignoreMobileResize` против дёрганья от адресной строки
- **Моушн-пакет** — marquee-мосты между главами (тёмный между 02 и 03), кастомный курсор с data-cursor подписями (pointer:fine), magnetic-кнопки (делегированно, сила ≤25%), параллакс обложки, живое плёночное зерно (steps-кадры)

## Креатив-детали («Архив оживает», раунды 2–3)

- **Штамп «Принято в архив»** — SVG с текстом по окружности на акте приёма и в подтверждении клуба; появляется «ударом» (scale 1.6→1)
- **Живые часы МСК** в шапке + координаты архива; живая дата и номер сборки в описи
- **Лупа цвета** в «Материалах» (pointer:fine): фото остаётся дуотоном, цвет виден через круг-маску за курсором
- **«Опись»** — полноэкранное оглавление из шапки: главы крупным Playfair с пигментами, мини-превью главы при наведении, Esc/навигация с Lenis stop/start
- **Печатная версия** — кнопка «Распечатать выпуск» в футере и @media print: тёмные главы инвертируются в бумагу, пины и декор снимаются, лукбук перестраивается в сетку
- **Кинетическая типографика hero** — вес слов заголовка растёт к курсору (Playfair variable `wght 400..900`, pointer:fine)
- **Шторки-титулы** — wipe-шторки глав несут номер и название («02 · Лукбук») как титульные листы журнала
- **Курсорный язык 100%** — data-cursor подписи на всём интерактиве: луки, товары, лупа, журнал, опись, свотчи, клуб, печать, футер

## Доступность и перф

- `prefers-reduced-motion`: полностью статичная версия — без прелоадера, пина, шторок и проявлений, весь контент виден сразу и сразу в цвете
- **Бюджет 60 fps выдержан** (замер CDP-зондом: avg 16.6 мс/кадр, worst 19 мс, dropped frames 0, long tasks 0 при непрерывном скролле):
  - пигмент `--chapter-accent` статичен на каждой главе (не скраб на `:root` — тот давал style recalc всего документа каждый кадр);
  - зерно — transform-кадры в собственном композитном слое (не background-position);
  - шапка без `backdrop-filter: blur` (плотный rgba);
  - marquee с паузой вне вьюпорта и одним ticker'ом; `will-change` у hero-media; quickSetter для прогресса лукбука
- Образы лукбука грузятся eager + preload первых трёх в `<head>`; `fetchpriority="high"` у hero; остальное — `loading="lazy"`; preconnect к Google Fonts
- LCP по спотчеку ~0.33 с (локально, headless)
- aria-pressed у свотчей/фильтров/сортировок, aria-live у счётчика каталога и клуба, Esc и focus-return у модалок, стейджа и описи
- Мобильная раскладка: 390px — лукбук в одну ленту (кадр по ширине), planche в одну колонку, каталог 2 колонки

## QA

Автотесты через Chrome DevTools Protocol (70 проверок + скриншоты глав):

```bash
python3 scripts/qa-norde.py            # десктоп 1440px
python3 scripts/qa-norde.py --mobile   # 390px
python3 scripts/qa-norde.py --rm       # prefers-reduced-motion
python3 scripts/qa-norde-lcp.py        # LCP-спотчек (порог 2500 мс)
python3 scripts/qa-norde-probe.py      # перф-зонд: FPS при скролле + long tasks (не часть сьюта)
# флаг --shot дополнительно сохраняет кадры в /tmp/norde-qa-*.png
```

Известная особенность: кадр `ch02-drift` в headless может содержать артефакт растрирования pinned-слоя (баг захвата Chrome, не страницы) — состояние дрейфа поэтому дополнительно проверяется на DOM-уровне.
