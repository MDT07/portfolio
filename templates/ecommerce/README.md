# Шаблон «NORDE Архив» — editorial-магазин

Демонстрационная витрина скандинавского магазина одежды и предметов дома, поданная как **архив-издание**: бумага, чернила, латунь, нумерованные главы. Полностью самодостаточный `index.html` — CSS и JS встроены, внешние библиотеки подключены по CDN.

Уровень **Editorial+**: borderless-сетка (главы текут без видимых границ), архивный дуотон всех фото — `grayscale(1) sepia(.22) contrast(1.06) brightness(1.02)`, крупные нумералы глав 01–05 на полях.

## Запуск

Открыть `index.html` в браузере — сборка и сервер не требуются.

```bash
open index.html        # macOS
# или просто двойной клик по файлу
```

## Главы

- **00 / Обложка** — обложка во весь экран (100svh): фото коллекции занимает правые 55% во всю высоту с paper-градиентным напылением, вертикальная мета выпуска; маска-ревил заголовка по словам. Мобила: фото нижние 44svh
- **01 / Манифест** — журнальный разворот на 12 колонок: pull-quote латунным курсивом, drop cap, пункты П.1.1–1.3
- **02 / Лукбук** *(тёмная)* — pinned горизонтальный дрейф шести образов со skew по скорости и прогресс-линией; кадр 62vw/640px, scrub 0.6 + anticipatePin; «Образ в корзину» добавляет комплект
- **03 / Planche** *(тёмная)* — Three.js: **Archive Runner NR-0202** (GLB), pinned scroll-камера по 4 ракурсам, scrub 0.6; спеки моно-шрифтом (текстиль / пена EVA / 290 г); свотчи через `KHR_materials_variants` — имена цветов читаются из самой модели (fallback — фото)
- **04 / Архив единиц** — borderless-картотека из 8 единиц хранения: текстовые фильтры-рубрики с точкой у активной, hover-lift карточек, ранний reveal (rootMargin 200px), quick-view; при входе в главу образ из 02 «перелетает» в первую карточку (FLIP, клон с дуотоном)
- **05 / Условия архива** — доставка, возврат, гарантия, оплата табличной вёрсткой
- **Футер** — постерный wordmark NORDE во всю ширину + колонки ссылок

## E-commerce ядро

Каталог, фильтрация, quick-view модалка (выбор размера, Esc закрывает), корзина-drawer с количеством/удалением/доставкой (бесплатно от 10 000 ₽) и оформлением в **Акт приёма** с номером и составом. Счётчик в шапке, toast-уведомления.

## Motion-стек (CDN)

- **Lenis** — плавный скролл (lerp 0.12), velocity-marquee реагирует на скорость
- **GSAP + ScrollTrigger** — прелоадер-счётчик (первый визит сессии), маски заголовков, curtain-wipe на главах 02/03/04, пины 02 и 03, FLIP-перелёт; `ignoreMobileResize` против дёрганья от адресной строки
- **Three.js** — загружается динамически (import map), только когда planche входит во вьюпорт

## Доступность и перф

- `prefers-reduced-motion`: полностью статичная версия — без прелоадера, пинов и шторок, весь контент виден сразу
- Образы лукбука грузятся eager + preload первых трёх в `<head>` (pinned-секция не должна догружать кадры на ходу); `fetchpriority="high"` у hero; остальное — `loading="lazy"`; preconnect к Google Fonts
- LCP по спотчеку ~0.7 с (локально, headless)
- Мобильная раскладка: 390px — лукбук в одну ленту, planche в одну колонку, каталог 2 колонки

## QA

Автотесты через Chrome DevTools Protocol (37 проверок + скриншоты глав):

```bash
python3 scripts/qa-norde.py            # десктоп 1440px
python3 scripts/qa-norde.py --mobile   # 390px
python3 scripts/qa-norde.py --rm       # prefers-reduced-motion
# флаг --shot дополнительно сохраняет кадры в /tmp/norde-qa-*.png
```

Известная особенность: кадр `ch02-drift` в headless при 390px может содержать артефакт растрирования pinned-слоя (баг захвата Chrome, не страницы) — состояние дрейфа поэтому дополнительно проверяется на DOM-уровне.
