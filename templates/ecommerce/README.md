# Шаблон «NORDE» — интернет-магазин

Демонстрационная витрина минималистичного магазина одежды и товаров для дома (скандинавская эстетика). Полностью самодостаточный `index.html` — CSS и JS встроены, зависимостей нет.

## Запуск

Открыть `index.html` в браузере. Сборка и сервер не требуются.

```bash
open index.html        # macOS
# или просто двойной клик по файлу
```

## Секции

1. **Header** — fixed, blur-подложка при скролле, корзина со счётчиком
2. **Hero** — editorial-подача: крупная типографика, фото коллекции, CTA
3. **Категории** — 4 карточки: Одежда / Обувь / Аксессуары / Дом (клик фильтрует каталог)
4. **Каталог** — 8 товаров, фильтр по категориям, hover «Быстрый просмотр»
5. **Quick-view** — модалка с фото, описанием, выбором размера, кнопкой «В корзину» (Esc закрывает)
6. **Корзина** — drawer справа: количество, удаление, подытог/доставка/итого, «Оформить заказ»
7. **Преимущества** — доставка, возврат, гарантия, оплата
8. **Footer** — колонки ссылок, mono-подпись

## Интерактив

Всё на чистом vanilla JS, работает при открытии файла напрямую:

- фильтрация каталога по категориям (в т.ч. через карточки категорий)
- quick-view модалка: выбор размера, добавление в корзину
- корзина с полным состоянием: +/− количество, удаление, расчёт доставки (бесплатно от 10 000 ₽), оформление заказа
- счётчик в шапке, toast-уведомления, плавный скролл, reveal-анимации
