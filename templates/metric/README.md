# Шаблон «METRIC — CRM поддержка для ведения бизнеса»

Полнофункциональная CRM-платформа уровня 2026 года в одном самодостаточном HTML-файле. Универсальная база + конструктор собственных систем: сделки, клиенты, задачи, аналитика, счета — и возможность собирать свои страницы и сущности с нуля.

## Запуск

Открыть `index.html` двойным кликом — работает без сборки и сервера (file://). Данные живут в `localStorage`, сброс — в «Настройках».

## Разделы

- **Дашборд** — KPI со спарклайнами, SVG-график выручки с кроссхаиром, воронка, live-лента активности, ближайшие задачи
- **Сделки** — канбан с drag-n-drop (pointer events) + таблица с сортировкой + drawer карточки с AI-подсказкой следующего шага
- **Клиенты** — компании и контакты, сортировка, профиль компании со связанными сделками
- **Задачи** — три статусные колонки + месячный календарь
- **Аналитика** — конверсия, средний чек, источники, лидерборд команды
- **Счета** — статусы, суммы по состояниям, drawer смены статуса
- **Конструктор** — сборка страниц из виджетов (drag-n-drop сетка 12 колонок, resize, сохранение) + кастомные сущности с полями (текст/число/сумма/дата/статус/список), появляются в сайдбаре с таблицей и CRUD
- **Настройки** — профиль, тема, язык, шорткаты, сброс демо

## Интерактив 2026

Командная палитра `⌘K` (навигация, действия, поиск по данным), горячие клавиши `G→D/P/C/T/A/I/B/S`, `C` — создание, toast-уведомления, empty states, имитация live-активности, METRIC AI — локальный чат-ассистент (сводки, прогноз, воронка, создание задач и сделок, черновики писем) без внешних API.

## Стиль

Своя айдентика (не наследует dev.developer): светлая Linear/Attio-подобная база + тёмная тема, акцент индиго `#4F46E5`. Onest + JetBrains Mono (кириллица). 1px бордеры, без градиентов. Данные — детерминированный сид (mulberry32), интерфейс RU/EN.
