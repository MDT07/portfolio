# PRIMARY TERRA — демо-шаблон девелоперской компании

Самодостаточный HTML-файл: открывается в браузере без сборки и сервера.

## Запуск

Открыть `index.html` в браузере — всё.

## Что внутри

- Hero с фоновым фото и drift-анимацией
- 001 — ключевые метрики с анимированными счётчиками
- 002 — каталог проектов с фильтром (жилые / коммерческие / инфраструктура), цифры по каждому проекту: цена за м², площади, рассрочка, статус
- 003 — технологии строительства (BIM, энергоэффективность, модульность, геомониторинг)
- 004 — контакты и форма заявки (демо-обработчик)
- Reveal-анимации на IntersectionObserver, фильтрация и счётчики на чистом JS

## Стек

HTML5 + CSS3 (кастомные свойства — токены) + Vanilla JS. Зависимостей нет.
